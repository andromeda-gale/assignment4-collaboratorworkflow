# Subtraction of integers

In order to subtract integers, visualize a number line where you have two values, x and y, that are positive.

The value, x, serves as the "starting value" on the number line. The other value, y, serves as how many steps left, when subtracting, to move.

The value x will move y units left when subtracting, resulting in the new value, z.

In short, your equations will be:
`x - y = z`

NOTE:

If y is negative, it's `x + y = z` as a negative value times a negative value equals a positive value.

If x is negative, it's `-x - y = z` as a negative value minus a positive value equals a negative value.

# Example
If x = 4; y = 2, find z.

`x - y = z`

`4 - 2 = z`

`2 = z`
